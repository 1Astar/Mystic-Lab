## 1. 结论

用户要在 **造命 + 八字 + 紫微** 右上角打开**同一份**玩法设置（跟当前角色）。  
默认 **全部关闭**。两层：

1. **玩法线总开** → 能不能玩 + 能不能产对应经验（关线 = 少一条产出，**不清档**）。  
2. **块/入口显示** → 壳上显不显；关着占位「已关闭 · 去设置开启」。

分类按 **玩法线**（学习闭环 / 推演 / 盲盒 / 周记 / 盘面穿梭 / 造命 RPG），**不要**再用「八字玩法=五行条」那种窄切。

多步引导文案（分号串）→ **分行短条**，禁止长分号一句。

---

## 2. 背景与问题

- 造命叠了灵根、限时词条、XP、问答；八字已有知识点、能量天平、【如果】、猜命盘、时光机、知识树等；紫微运限有日常/周常。  
- 无统一开关时，用户无法「先知命、少玩法」或关掉不想玩的产出来源。  
- 知识树里已有长句：`总览拖「能量天平」…；运势…；猜命盘…；命盘…`，挤成一行难读。

现有偏好可参考：`mystic-lab-use-profile-in-readings`、`mystic-lab-liuyao-mode`、`mystic-lab-ai-settings`。造命进度键与玩法 prefs **分离**。

---

## 3. 目标与非目标

### 目标

1. 按角色持久化玩法 prefs；默认全关。  
2. 造命 / 八字 / 紫微右上角进同一设置面板。  
3. 两层开关：线总开（玩+经验）+ 块显示。  
4. 关 RPG → **运限任务一起停**（不挂条、不结算新属性/XP）。  
5. 关线 → 对应经验来源停；旧进度保留。  
6. 关块 → 原壳结构保留，占位可点进设置。  
7. 多步说明改为分行列表（含知识树 howto 等现存长句）。  
8. 知识点入口与 RPG **分入口**（可共用经验叙事，但不绑死一个按钮）。

### 非目标

- 本轮不清档、不做「重置进度」。  
- 本轮不新建尚未存在的玩法本体（盲盒/知识树等已有则接线；没有的线先出开关占位 + `comingSoon` 文案）。  
- 不改为「各模块各一份互相独立的 prefs」。  
- 不挡紫微/八字**看盘/解读主路径**（只挡玩法层与结算）。

## 4. 玩法线与块

| 线 id | 名称 | 总开管什么 | 块/入口（显示层） | 经验产出 |
|---|---|---|---|---|
| `learn` | 学习闭环 | 为什么这么解、知识点收集、知识树升级相关写入 | 知识点小入口、知识树进度条、学习页块 | 八字 learn XP / 知识点 |
| `sim` | 推演模拟 | 【如果】互动可玩与记互动 | 运势 Tab【如果】区 | 互动事件 / learn XP |
| `guess` | 复习盲盒 | 猜命盘答题与记胜 | 猜命盘入口 | 猜对 / learn XP |
| `weekly` | 周记对照 | 脑内天气预报对账 | 周记/天气入口 | 周记类 |
| `shuttle` | 盘面穿梭 | 时光机互动；紫微觉醒加分写入（可选子块） | 命盘时光机；造命觉醒引导；限时词条（子块） | 互动；造命轴成长（若挂子块） |
| `rpg` | 造命 RPG | 运限日常/周常、造命问答打卡、craft XP 结算 | 星盘 XP 卡；「你现在最想问」；运限任务条 | craft XP / 轴打卡 |

**子块示例（显示层，可再拆）：**

- `learn.knowledgeChip` — 总览「知识点」小按钮/芯片  
- `learn.tree` — 知识树/称号进度  
- `sim.ifBlock` — 运势【如果】  
- `guess.entry` — 猜命盘入口  
- `weekly.weather` — 脑内天气  
- `shuttle.timeMachine` — 时光机  
- `shuttle.spiritRadar` — 造命灵根雷达六维  
- `shuttle.yearBuff` — 本年限时词条  
- `shuttle.comboAch` — 图鉴组合成就  
- `shuttle.awakenTip` — 盘面觉醒引导  
- `rpg.xpCard` — 星盘 XP  
- `rpg.craftQuests` — 造命高频问答  
- `rpg.ziweiDaily` — 运限任务条（与线总开强绑定：线关则强制不显示且不结算）

**规则：**

- 线 `enabled === false` → 该线所有块视为隐藏 + **禁止新结算**。  
- 线开、块关 → 可结算（若用户从深链进入玩法）但壳上不展示；产品默认：**深链进入时若块关，仍给占位回设置**（P0 可对深链只拦结算、仍允许玩，二选一在计划里定；**推荐深链也可玩但顶部条提示「展示已关」**）。  
- **推荐 P0：** 线关 = 完全不能玩该线；块关 = 仅藏入口/块，深链仍可完成一次并产经验（避免死链）。运限任务例外：`rpg` 关则深链也不结算。

## 5. 数据模型

```ts
// localStorage key
const PLAY_PREFS_KEY = 'mystic-lab-play-prefs-v1';

type PlayLineId = 'learn' | 'sim' | 'guess' | 'weekly' | 'shuttle' | 'rpg';

type PlayPrefs = {
  lines: Record<PlayLineId, {
    enabled: boolean;
    blocks: Record<string, boolean>; // 缺省 = false（与默认全关一致）
  }>;
};

type PlayPrefsStore = {
  byPerson: Record<string, PlayPrefs>;
};
```

**默认：** 任意缺失 person / line / block → `false`。  
**迁移：** 无键 = 新默认全关（行为变化：老用户造命块会先占位，需开设置——符合「默认关闭」拍板）。

读写：`loadPlayPrefs(personId)` / `savePlayPrefs(personId, prefs)` / `isLineEnabled` / `isBlockShown`。  
备份：加入 `journal/backup.ts` 的 `BACKUP_KEYS`。

## 6. UI

### 6.1 入口

- 造命、八字（解读/总览）、紫微（阅读剧场）**右上角**齿轮或「玩法」按钮 → `openPlayPrefsSheet(personId)`。  
- 与「自己 ▾」角色切换并列，不抢主导航。

### 6.2 设置面板

底部 sheet（复用造命 tip / ziwei-wq 类卡片风格，样式进 **craft 或共享 `play-prefs.css`**，避免仅挂 ziwei.css）。

结构：

```
玩法设置
跟当前角色 · {昵称}
默认关闭；打开后才产对应经验

[学习闭环]     (开关)
  · 知识点入口
  · 知识树
  怎么玩：
    · 解读页 ·【为什么这么解？】收入知识库
    · …

[推演模拟]     (开关)
  · 运势【如果】
  怎么玩：
    · 运势 Tab · 点【如果】模拟

…（各线同构）

[造命 RPG]     (开关)
  · 星盘 XP
  · 高频问答
  · 运限任务（关线则运限条停）
```

「怎么玩」**禁止**分号长句；一律：

```
· 总览 · 拖「能量天平」杠杆
· 运势 · 点【如果】模拟
· 猜命盘 · 答一题
· 命盘 · 拖「时光机」
```

### 6.3 壳占位

模块壳不变；块关时原位置：

```
××已关闭 · 去设置开启
```

可点打开同一 sheet 并滚动到对应线。

### 6.4 知识点小按钮

总览区「知识点 0 · …」可收成 **小芯片/按钮**（与 RPG 入口分离）。线/块关 → 芯片变「已关闭」或占位。

## 7. 行为矩阵（结算）

| 条件 | 造命 XP / 轴打卡 | 运限任务条 | 八字 learn 写入 | 看盘/解读正文 |
|---|---|---|---|---|
| `rpg` 关 | 不写入 | 不挂载 | — | 不受影响 |
| `learn` 关 | — | — | 不收集/不升级写入 | 解读可看；【收入知识库】禁用或提示开设置 |
| `sim`/`guess`/`shuttle`/`weekly` 关 | — | — | 对应互动不记 | 对应 UI 占位 |
| 仅块关、线开 | 深链可写（P0 推荐） | 块关则不挂条 | 同左 | 入口藏 |

## 8. 实现分期

### P0（本轮必须）

1. prefs store + 默认全关 API。  
2. 统一设置 sheet + 三入口。  
3. 造命页：按线/块显隐灵根相关、XP、问答；占位。  
4. 紫微：`rpg` 关 → 不挂运限任务条、结算 early-return。  
5. 八字：`learn`/`sim`/`guess`/`shuttle`/`weekly` 接线现有入口；知识点芯片。  
6. 知识树等 **howto 长句改分行列表**（`learn-tree.ts` 等）。  
7. backup key。

### P1

- 设置内「一键全开/全关」。  
- 深链顶部「展示已关」条。  
- 未完工玩法线的 `comingSoon` 说明。  
- 经验预览：「当前开启线预计可产经验来源」。

### P2

- 学习闭环总蓝图可视化（等级门槛 × 各线喂经验）。  
- 与 Star PM 灵感字段同步（非必须）。

## 9. 文案与视觉规范

- 多步、分号类说明 → **换行列表**；每步 `场景 · 动作`。  
- 开关标签短；说明放线内折叠或「怎么玩」列表。  
- 对比度跟金墨 token（`--gold-ink`），与造命 tip 一致。  
- 弹层样式 **不得只依赖 ziwei.css**（造命路由可能未加载）。

## 10. 测试要点

1. 新角色：全关；造命见占位；运限无任务条。  
2. 只开 `rpg`：造命 XP/问答与运限任务恢复；八字知识点仍关。  
3. 开 `learn` + `knowledgeChip`：总览芯片可进；关块后芯片占位。  
4. 换角色：prefs 隔离。  
5. 刷新/备份恢复 prefs。  
6. 长 howto 在窄屏为多行，无横向溢出。
